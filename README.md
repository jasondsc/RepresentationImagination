# RepresentationImagination
Studying how people build mental representations in imagination for planning.

This GitHub contains:
1) the Maze stimuli used in the three experiments
2) The task code for all three experiments
3) The analysis scripts in R (.rmd files) for the three experiments
4) The code used to run the spatial and random forgetting models (in the ForgetModels folder)

Dependencies:
To run the forgetting models and to get the predictions from the sVGC and JIT models please install the VGC and JIT packages. These can be found in the links provided above.

This GitHub contains the codes for da Silva Castanheira et al (2026) In prep.
